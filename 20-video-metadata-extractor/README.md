# 20-video-metadata-extractor

## Description
A backend API project.

## Technologies Used
Node.js

## Prerequisites
- Node.js (v14+ recommended)
- npm

## Setup Instructions
```bash
npm install
```

## Run Instructions
```bash
npm start
```

## Example API Endpoints / Usage
- \`POST /metadata\` - Extract metadata (Body: \`{ "videoUrl": "path_or_url" }\`)
