# 19-notification-service

## Description
A backend API project.

## Technologies Used
Node.js

## Prerequisites
- Node.js (v14+ recommended)
- npm

## Setup Instructions
```bash
npm install
```

## Run Instructions
```bash
npm start
```

## Example API Endpoints / Usage
- \`POST /notify\` - Queue notification (\`userId\`, \`message\`)
- \`GET /status/:id\` - Check notification status
