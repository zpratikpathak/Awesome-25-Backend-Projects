# 🛡️ Security Policy

## 📋 Supported Scope

This repository provides educational backend demo projects across different programming languages and runtimes.

| Version / Scope | Supported | Notes |
| --------------- | --------- | ----- |
| Main branch (`25 + 1 Projects`) | ✅ Yes | Educational & reference fixes |
| Production deployments | ⚠️ No | Educational demos; not hardened for production |

---

## ⚠️ Educational Demos Notice

Please note:
- The projects in this repository are **learning demos**, designed to illustrate backend concepts, protocols, and architectures in clean, self-contained examples.
- Many projects use **in-memory data stores** and basic error handling suitable for learning environments.
- **Do not deploy these projects directly to public production environments** without a full security audit, authentication hardening, persistence layer, TLS termination, and input sanitation review.

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or potential issue in any of the projects:

1. **Do not create a public issue** with exploit details or sensitive payloads.
2. Please report your findings by contacting the repository maintainer directly via GitHub or opening a private advisory if enabled on the repository.
3. Include in your report:
   - Project name / folder (e.g., `07-basic-auth-system`).
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Suggested fix or mitigation, if available.

We appreciate responsible disclosure and will review reported issues promptly. Thank you for helping keep the open source community safe! 🤝
